# Nabhalipi
It's an App that is aimed to make my teachers' lives a bit easier. In my school teachers have to write the results of each student in a pre-made printed result sheet. The result sheet we get is hand-written. Techers need to write the same results for each students in different documents. So, the aim of this app is to make it automated. Teachers can type the results in the app while examining each student's answer sheet, and when all marks are done for a student the app will automatically put it in a ready-to print result sheet. This will eliminate the hand-written process completely. This is specially made for my school so the exam and marking rules in this app will be specifically about my school.
